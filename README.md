# Tamaddon v21.1 — Stable Base Geographic Network

این نسخه برای رفع مشکل صفحهٔ خالی v21 ساخته شده است.

- بدون Leaflet، Turf یا CDN برای هستهٔ نقشه
- شبکهٔ سلولی از پیش محاسبه و داخل index.html جاسازی شده
- نقشهٔ پایهٔ سبک Natural Earth نیز داخل فایل قرار دارد
- خطوط داخلی سلول‌ها به‌صورت پیش‌فرض خاموش است
- دکمهٔ «نمایش شبکهٔ پایه» برای debug وجود دارد
- zoom/pan با SVG داخلی کار می‌کند
- در صورت خطای JavaScript، پیام خطای واضح داخل نقشه نمایش داده می‌شود

برای GitHub Pages، index.html و README.md را در root مخزن آپلود کنید.
