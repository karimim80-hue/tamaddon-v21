# Tamaddon v21 — Base Geographic Network

این نسخه معماری نقشه را از «پلیگان‌های مستقل» به یک شبکهٔ جغرافیایی پایهٔ ثابت تغییر می‌دهد.

- یک master hex grid برای کل محدودهٔ مطالعه ساخته می‌شود.
- هر سلول فعال دقیقاً به یک زیرناحیهٔ تاریخی تخصیص می‌یابد.
- سلول‌ها مرزهای مشترک دقیق دارند؛ بنابراین بین زیرناحیه‌های فعال شکاف سفید ایجاد نمی‌شود.
- خطوط داخلی سلول‌ها به‌صورت پیش‌فرض رندر نمی‌شوند.
- فقط مرز خارجی قلمرو نمایش داده می‌شود.
- دکمهٔ «نمایش شبکهٔ پایه» برای دیباگ، سلول‌های زیرین را موقتاً نشان می‌دهد.
- smoothing فقط روی مرز بیرونی و بسیار خفیف انجام می‌شود؛ دیگر از buffer سنگین برای گرد کردن هر ناحیه استفاده نمی‌شود.

این نسخه هنوز از بازسازی‌های مرجع فعلی برای تعیین محدودهٔ تاریخی استفاده می‌کند؛ گام بعدی، جایگزینی ماسک‌های مرجع با داده‌های جغرافیایی/تاریخی دقیق‌تر است.
